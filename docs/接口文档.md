# WowsApi 接口文档

> 面向 `wows-api`（jar 2.5.x）当前已实现的全部接口。
> 文档里的字段清单来自**真实响应**（国服账号 `7060948811`、亚服账号 `2022515210` 等），
> 与代码中的结构体一一对应；字段漂移由 `SchemaMonitorTest` 监视（见文末）。

## 1. 总览

### 1.1 两条通道

| 通道 | 域名 | 请求类 | 说明 |
| --- | --- | --- | --- |
| vortex | `vortex.<server>` / `clans.<server>` | `VortexHttp` | 战舰世界官网同款接口，**不需要令牌**，覆盖账号/战舰/军团/资源 |
| 官方开发者API | `api.<server>` | `ApiHttp` | WG 官方 API，需要 `application_id`（莱服用 `/mk/` 前缀 + 307 握手，由 `HttpTransport` 自动处理 cookie 与重定向） |

服务器枚举 `WowsServer`：

| 枚举 | code | 域名后缀 | 支持官方API |
| --- | --- | --- | --- |
| CN | cn | wowsgame.cn | 否 |
| ASIA | asia | worldofwarships.asia | 是 |
| EU | eu | worldofwarships.eu | 是 |
| NA | na | worldofwarships.com | 是 |
| RU | ru | korabli.su | 是 |

`server.vortex()` / `server.clans()` / `server.api()` / `server.ptVortexServer()` 分别给出对应域名。

### 1.2 入口类

| 类 | 覆盖范围 |
| --- | --- |
| `WowsHttpUserTools` | 账号：详情、搜索（vortex + 官方） |
| `WowsHttpShipTools` | 战舰：战舰列表（vortex）、战舰统计/战绩/徽章（官方） |
| `WowsHttpClanTools` | 军团：详情、成员、搜索（vortex + 官方）、赛季 |
| `WowsEncyclopediaTools` | 官方词典（glossary） |
| `WowsBox` / `WowsLootBox` / `WowsResources` / `RequestVortexResourcesInfo` | 资源：箱子列表、箱子详情、道具、狗牌/舰船资料 |
| `ClanRankUtils` | 军团排位榜（自动分页） |

### 1.3 通用约定

- **状态校验**：vortex 响应带 `status` 字段，`BasicException.status(node)` 会在非 `ok` 时抛异常。
- **隐藏战绩**：接口返回 `hidden_profile=true` 时抛 `HiddenProfileException`。
- **超时**：全部走 `HttpCodec.requestTimeout()`（默认 3 秒，`HttpCodec.updateTimeout(int)` 修改）；`HttpCodec.client()` 是全局共享的 `HttpClient`（连接池复用、不跟随重定向、不挂 CookieHandler，重定向/Cookie 由 `HttpTransport` 按主机处理）。
- **压缩**：请求只声明 `gzip, deflate`，`HttpCodec.response` 负责解压与状态码校验——它是所有响应的唯一解码出口。
- **缺字段容错**：Jackson 3 的 `asXxx()` 在字段缺失/null 时抛异常，库内统一用带默认值的重载，接口新增字段不会导致解析失败。
- **时间字段**：vortex 的时间多为 ISO 字符串（如 `2026-06-15T11:21:44.918201`）或 Unix 秒；结构体保留原始形态（`String`/`double`），需要毫秒时间戳时用 `DateUtils`。

## 2. vortex 接口

### 2.1 接口清单

| 接口 | 调用 | 返回结构 |
| --- | --- | --- |
| `GET /api/accounts/{accountId}/` | `new WowsHttpUserTools(client, server).userVortex(accountId)` | `VortexUserInfo` |
| `GET /api/accounts/search/autocomplete/{keyword}/` | `...searchUserVortex(keyword)`（国服专用 `searchUserVortexCn`） | `List<VortexSearchUser>` |
| `GET /api/accounts/{accountId}/ships/{battleType}/` | `new WowsHttpShipTools(client, server, accountId).vortex().shipList(type)` | `VortexUserShip` |
| `GET /api/accounts/{accountId}/clans/` | `new WowsHttpClanTools(client, server).vortex().userSearchClanVortex(accountId)` | `VortexSearchClanUser` |
| `GET /api/clanbase/{clanId}/claninfo/` | `...vortex().clanInfoVortex(clanId)` | `VortexClanInfo` |
| `GET /api/members/{clanId}/?battle_type={type}` | `...vortex().clanUserListInfoVortex(clanId[, type])` | `VortexClanStatisticsInfo` |
| `GET /api/members/{clanId}/?battle_type=cvc&season={n}` | `...vortex().clanUserListInfoVortex(clanId, season)` | `VortexClanStatisticsInfo` |
| `GET /api/search/autocomplete/?search={tag}&type=clans` | `...vortex().searchClanVortex(tag)` | `List<VortexSearchClan>` |
| `GET /api/ladder/structure/?realm={realm}[&clan_id=..&season=..]` | `new ClanRankUtils().getRanks(server, season)` | `List<ClanRankInfo>` |
| `POST /api/graphql/glossary/`（operationName=Lootbox） | `WowsBox.request(...)` | `List<WowsBox>` |
| `POST /api/graphql/glossary/`（operationName=Items） | `WowsResources.request(...)` | `List<WowsResources>` |
| `POST /api/graphql/glossary/`（operationName=getGlossData） | `RequestVortexResourcesInfo.request(...)` | `RequestVortexResourcesInfo` |
| `GET /api/get_lootbox/{lang}/{lootboxId}/` | `WowsLootBox.request(server, language, lootboxId)` | `WowsLootBox` |

> graphql 是「一个 URL 多个 schema」，三个 operation 的响应形状完全不同，必须区分（监视基线里用 `#Lootbox` / `#Items` / `#getGlossData` 后缀区分）。
> `battleType` 取值来自 `WowsBattlesType`：`pvp` / `pvp_solo` / `pvp_div2` / `pvp_div3` / `rank_solo`。
> `isPtServer=true` 时走测试服（`vortex.worldofwarships.pt` / `vortex-rpt.korabli.su`）。

### 2.2 账号详情 `/api/accounts/{accountId}/` → `VortexUserInfo`

响应外层：`{"status": "ok", "data": {"<accountId>": { ... }}}`。

`data.<accountId>` 字段（已全部有结构体）：

| 字段 | 类型 | 结构体 | 说明 |
| --- | --- | --- | --- |
| name | string | `VortexUserInfo#name` | 昵称 |
| created_at | number | `VortexUserInfo#created_at` | 账号创建时间(Unix 秒) |
| activated_at | number | `VortexUserInfo#activated_at` | 账号激活时间(Unix 秒) |
| visibility_settings | boolean | `VortexUserInfo#visibility_settings` | 战绩可见性 |
| dog_tag | object | `DogTag` | texture_id / symbol_id / border_color_id / background_color_id / background_id |
| statistics | object | `VortexUserInfoStatistics` | 见下表 |
| hidden_profile | boolean | 触发 `HiddenProfileException` | 仅在隐藏战绩时出现 |

`statistics` 字段（16 个）：

| 字段 | 结构体 | 说明 |
| --- | --- | --- |
| basic | `Basic` | leveling_tier / created_at / leveling_points / karma / last_battle_time |
| pvp / pve / pvp_solo / pvp_div2 / pvp_div3 / rank_solo / rank_div2 / rank_div3 / rank_old_solo / rank_old_div2 / rank_old_div3 | `VortexShipInfo` | 各战斗类型的汇总数据块（账号维度为 80 字段，单船为其中 64 字段） |
| mark_of_excellence | `VortexMarkOfExcellence` | 优秀标记：personal / division（各含 name、grade_class、ships_count、percentile、grades[]） |
| rank_info | `Map<赛季, Map<分组, Map<段位, VortexRankInfo>>>` | 排位进度：rank / best_rank_in_sprint / victories / max_stars_total / battles / stars / qualification_status / rank_best / stage |
| seasons | `VortexSeasons` | 赛季战绩：`seasons[赛季][分组][战斗类型]` = `VortexShipInfo`，另有 `VortexSeasons#stats(season, battleType)` 便捷取值 |
| mastery_sign | string | 精通签名 |

> `statistics` 里出现哪些战斗类型取决于该账号打过什么，结构体对所有已知类型都留了字段，缺失即默认值。

### 2.3 战舰列表 `/api/accounts/{accountId}/ships/{battleType}/` → `VortexUserShip`

| 节点 | 结构体 | 说明 |
| --- | --- | --- |
| `data.<accountId>.name / created_at / activated_at / visibility_settings` | `VortexUserShip` | 账号信息 |
| `data.<accountId>.statistics.<shipId>.{battleType}` | `VortexShipInfo` | 该船该模式的战斗数据（64 字段，账号汇总块的子集） |
| `data.<accountId>.statistics.<shipId>.mastery_sign` | `VortexShipStatistics#masterySign` | 精通签名 |
| `data.<accountId>.statistics.<shipId>.mark_of_excellence` | `VortexShipMarkOfExcellence` | personal / division，各含 ship_id、grade{name, grade_class}、percentile、battles_left、achieved_at |

`VortexUserShip#toShipInfoList()` 会把结果转成 `ShipInfo`（含场均、命中率、KD 等派生指标）；`VortexShipStatistics` 里同时保留了原始战斗数据与精通签名、优秀标记。

## 5. 字段漂移监视（可选）

接口改版（字段增删/类型变化）可以用内置的监视跑一遍：

```powershell
# 在线探测 + 与基线比对（只读；出现 removed/typeChanged 时退出码 1）
powershell -NoProfile -ExecutionPolicy Bypass -Command "& '.workbuddy/build.ps1' -SkipMain -SkipTest -Run com.shinoaki.wows.SchemaMonitorTest"
# 确认变化符合预期后写回基线
powershell -NoProfile -ExecutionPolicy Bypass -Command "& '.workbuddy/build.ps1' -SkipMain -SkipTest -Run com.shinoaki.wows.SchemaMonitorTest -RunArgs @('--update')"
```

- 基线：`src/test/resources/schema-baseline/*.json`（入 git 作契约）。
- 字段覆盖自检：`VortexFieldCoverageTest`（解析真实响应并逐层核对「JSON 有的字段结构体是否都有」）。覆盖账号详情、战舰列表、军团详情/成员、graphql getGlossData、箱子详情；账号/战舰/军团取 `target/cn-dump`（没有就联网抓国服 7060948811），资源类取 `target/schema-raw` 的采集。
- 官方API 探测需要 `WOWS_APP_ID` 环境变量。
