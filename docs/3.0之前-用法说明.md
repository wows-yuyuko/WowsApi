# 3.0 之前（2.x）用法说明

> 本文件描述 **3.0 之前**的旧 API。3.0 起请求层整体重写，旧入口进入断代清理：
> `WowsHttpUserTools` / `WowsHttpClanTools` / `WowsHttpShipTools` / `WowsEncyclopediaTools` / `ClanRankUtils`
> 五个类已标记 **`@Deprecated`**，将在 3.0.0 正式发布后的清理中删除。
>
> **迁移状态**：3.0 的 22 个端点已**全部迁入**新架构（含战舰 / 军团 / 排行 / 箱子 / 资源 / 词典），
> 迁移期旧写法仍完全可用（底层 `HttpCodec` / `HttpTransport` 已改为委托 3.0 底座，
> 共享同一 HttpClient 与同一份超时/代理配置）。新写法见 [README](../README.md)；
> 「旧 → 新」映射表见本文 §5。

---

## 1. 旧版请求通道

请求发送按业务分为两个通道（位于 `com.shinoaki.wows.api.codec` 包），后续站点策略变动只需改动对应通道：

- `ApiHttp` — 官方开发者API（`server.api()` 域名，即 `/wows/**` 与莱服 `/mk/**`）。
- `VortexHttp` — vortex 接口（`vortex.*` / `clans.*` 域名）。

两个通道都经由共用的低层传输（`HttpTransport`，公开类）发送。**Cookie 管理 + 重定向跟随按主机开启**，默认仅注册 `api.korabli.su`（莱服官方API，存在 `307 + Set-Cookie: bp_chl=...` 反爬握手）：

- 注册主机：无 cookie 请求自动附带/保存 cookie 并跟随重定向（最多 2 次重放），cookie 进程内共享、按域名隔离、线程安全；
- 并发冷启动单飞：同一主机无有效 cookie 时只允许一个线程发起握手，其余线程复用其 cookie，避免并发 307 风暴；
- 429 限流（该 WAF 对并发突发会返回 429）：自动按 `Retry-After` / 指数退避等待后重试，最多 3 次；
- 其它主机（vortex/clans、以及 ASIA/EU/NA/CN 官方API）：走普通快速通道，单次发送直接返回，**零额外开销**；
- 未来若某服务器出现同样防护，一行开启：`HttpTransport.enableCookieRedirect("主机")`；
  不需要默认莱服处理时可用 `HttpTransport.disableCookieRedirect("api.korabli.su")`；
- 调用方即使使用默认的 `HttpClient.newBuilder().build()`（不跟随重定向、无 cookie handler）也能正常工作，无需自行配置。

> 3.0 备注：上述实现已迁入 `transport.HostPolicy`，旧 `HttpTransport` / `HttpCodec` 仅做委托；新代码请直接使用 3.0 写法。

## 2. 旧版用法（`WowsHttp*Tools`）

所有 Tools 构造都需要自行传入共享 client：`HttpClient client = HttpCodec.client();`

### 2.1 玩家信息 `WowsHttpUserTools`

```java
WowsHttpUserTools tools = new WowsHttpUserTools(client, WowsServer.ASIA);

// —— vortex ——
tools.searchUserVortex("JustOn");                     // 玩家搜索
tools.searchUserVortexCn("西行寺");                    // 国服搜索（对 503 限流静默返回空表）
tools.userVortex(2022515210L);                        // 玩家详情（公开数据）
tools.userVortex(2022515210L, "分享token");            // 玩家详情 + 私有数据（分享凭证只对该账号有效）

// —— 官方开发者API（appId 即 application_id）——
tools.searchUserDevelopers(appId, "JustOn");                    // 账号搜索
tools.userInfoDevelopers(appId, 2022515210L);                   // 账号详情
tools.userInfoDevelopers(appId, 2022515210L, accessToken);      // 账号详情 + private.* 私有数据
tools.accountInfoDevelopers(appId, 2022515210L);                // 3 请求聚合：详情 + 所属军团 + 军团详情
```

### 2.2 军团信息 `WowsHttpClanTools`

```java
WowsHttpClanTools clan = new WowsHttpClanTools(client, WowsServer.ASIA);

// —— vortex ——
clan.vortex().userSearchClanVortex(accountId);              // 玩家所属军团（非 API 服查无返回 404 → 空对象）
clan.vortex().clanInfoVortex(clanId);                       // 军团详情
clan.vortex().clanUserListInfoVortex(clanId);               // 成员战绩（默认 pvp）
clan.vortex().clanUserListInfoVortex(clanId, "cvc", 35);    // 指定战斗类型 / 赛季
clan.vortex().searchClanVortex("YU_RI");                    // 军团搜索

// —— 官方开发者API ——
clan.developers(appId).userSearchClanDevelopers(accountId); // 玩家所属军团
clan.developers(appId).clanInfoDevelopers(clanId);          // 军团详情（含成员列表）
clan.developers(appId).searchClanDevelopers("YU_RI");       // 军团搜索
clan.developers(appId).season();                            // 赛季/联赛（language 硬编码 zh-cn）
```

### 2.3 战舰信息 `WowsHttpShipTools`

```java
WowsHttpShipTools ship = new WowsHttpShipTools(client, WowsServer.ASIA, accountId);

// —— vortex ——
ship.vortex().shipList(WowsBattlesType.PVP);                // 战舰战绩列表
ship.vortex().shipList(WowsBattlesType.PVP, "分享token");    // 带私有数据
ship.vortex().shipListMap(new WowsBattlesType[]{WowsBattlesType.PVP, WowsBattlesType.RANK_SOLO});
// 莱服专属战斗类型（brawl/clan/rating* 等）仅 RU 可用，其它服调用抛 IllegalArgumentException

// —— 官方开发者API ——
ship.developers(appId).shipList();          // 战舰统计（pvp + 历史子类型）
ship.developers(appId).shipOperList();      // 全量 extra（14 类块，含联合作战/排位/行动/军团战）
ship.developers(appId).shipBadges();        // 徽章（莱服不支持，旧实现静默返回空 Map）
ship.developers(appId).shipListOa(accessToken);
```

### 2.4 词典 `WowsEncyclopediaTools`

```java
DevelopersGlossary glossary = new WowsEncyclopediaTools(client, WowsServer.ASIA)
        .developers(appId)
        .glossary();
```

### 2.5 资源与箱子

```java
// 箱子详情（isPtServer 变体：request(true, server, language, lootboxId)）
WowsLootBox box = WowsLootBox.request(WowsServer.ASIA, VortexResourcesLanguage.SG, lootboxId);

// 以下三个旧签名带 throws IOException, InterruptedException, BasicException（旧实现直发，未走通道）
List<WowsBox> boxes = WowsBox.request(WowsServer.ASIA, VortexResourcesLanguage.SG);          // graphql：箱子列表
List<WowsResources> items = WowsResources.request(WowsServer.ASIA, VortexResourcesLanguage.SG); // graphql：资源列表
RequestVortexResourcesInfo index = RequestVortexResourcesInfo.request(WowsServer.ASIA, VortexResourcesLanguage.SG); // graphql：资源索引
```

语言枚举：`VortexResourcesLanguage.SG/CN/EN/RU`（zh-sg / zh-cn / en / ru）。

### 2.6 军团排行 `ClanRankUtils`

```java
// clan_id 游标分页拉取整个军团排行的清单（realm 按服：CN/RU=global、ASIA=sg、EU=eu、NA=us）
List<ClanRankInfo> ladder = new ClanRankUtils().getRanks(WowsServer.ASIA, season);
```

### 2.7 超时与代理（`HttpCodec`）

```java
HttpCodec.updateTimeout(20);                                  // 请求超时（秒，默认 3）
HttpCodec.updateProxySelector(ProxySelector.of(new InetSocketAddress("127.0.0.1", 7890))); // 全局代理；null = 直连
HttpClient client = HttpCodec.client();                       // 共享 client（构造各 Tools 时传入）
```

## 3. 2.x 版本变更历史

### 2.0.3 起

增加同步方法执行。

### 2.3.0 起

Jackson 升级到 Jackson 3，代码不再向下兼容。

### 2.6.0 起

数据模型（record）按真实响应补齐字段，部分 record 的构造器签名有变化：

- vortex：`VortexShipInfo` 64→80 字段；新增 mark_of_excellence/rank_info/seasons/visibility_settings 等结构；
- 官方API：`DevelopersShipBattleType` 36→47 字段；账号/军团/词典补齐未解析字段；
- `ShipInfo` 新增 `source`（来源标记）与 `hasBasicXp()/hasDbomb()/hasOtherHitRatio()/hasLastBattleTime()/hasExpansion()`；
- **直接 `new` 这些 record 的下游代码需要跟着改**（用库提供的 `parse(...)`/`to(...)` 工厂方法则不受影响）。

### 2.7.0 起

支持莱服（korabli.su）分家后的字段与战斗类型：

- vortex：`VortexShipInfo` 80→104 字段（莱服 +18：助攻/水雷/副炮/版本计数；oper_mm 再 +6：tasks_completed0..5，其它服恒为 0）；
- vortex 账号统计新增莱服专属数据块 brawl/clan/oper_mm/rank/rank_old/rating/rating_div/rating_solo 与 `rating_info`；`Basic` 加 `mastery_rank`；
- 莱服战斗类型一度用独立枚举 `WowsBattlesTypeRu`（后于同日合并为单枚举 `WowsBattlesType` + 服务器标识：每个值带 `code` 与 `servers`，
  方法 `isCommon()/isExclusive()/supportedOn(server)/servers()/code()`；通用 14、莱服专属 8）；
- 官方API：`DevelopersShipBattleType` 47→61 字段（莱服 +14）；莱服的官方通道不返回侦查伤害；
- `ShipInfo` 新增 `assistInfo`（助攻）与 `minesAgro`（水雷潜在，只有 vortex 的莱服数据有）；`MaxInfo` 加 maxAssistDamage/maxAssistKills；
- 老缓存兼容：`ShipInfo`/`MaxInfo` 的紧凑构造器把新字段归一为空值，2.6.x 的 Java 序列化数据仍可读。

### 2.7.1 起

箱子接口补莱服字段（依赖同步升级）：

- 依赖：jackson 3.0.4 → **3.2.3**、zstd-jni 1.5.7-7 → **1.5.7-22**；
- 箱子：同一个箱子 ID 在两服**不是同一个箱子**（实测 4288861104，奖励 255 vs 218、`isPremium` true vs false），
  莱服多 `quotesTitle/rarity/sortOrder`，把保底 `filler/savePoint` 从箱子级挪到槽位级，
  且不返回 `tags/price/cancharge/cardprob/clanresource/dogtagprob/epicprob/nestinglevel`（解析后是默认值，别当真实数据）；
- `WowsLootBox` 加 `quotesTitle/rarity/sortOrder`；`WowsLootBoxSlot` 加 `filler/savePoint`；
  `WowsLootBoxRewardData` 加 `rarity/l10nRarity/sortOrder`；`WowsLootBoxReward` 补上两条通道都有的 `defaultCrew`。

## 5. 旧 → 新（3.0）映射表

> 全部端点均已迁移（✅）；新写法详见 [README](../README.md)。

| 旧写法 | 3.0 写法 | 状态 |
|---|---|---|
| `new WowsHttpUserTools(client, server)` | `WowsApi.of(server)`（不再需要自建/传入 client） | 已迁移 |
| `tools.userVortex(id[, token])` | `api.vortex().user(id)`（凭证配在实例上：`.shareToken(id, token)`；或调用级 `user(id, ShareToken.of(id, token))`） | 已迁移 |
| `tools.searchUserVortex(name)` | `api.vortex().search(name)` | 已迁移 |
| `tools.searchUserVortexCn(name)` | `api.vortex().search(name, RateLimitPolicy.TOLERANT)`（显式容错，不再静默吞 503） | 已迁移 |
| `tools.searchUserDevelopers(appId, name)` | `api.developers().search(name)`（applicationId 配在实例上） | 已迁移 |
| `tools.userInfoDevelopers(appId, id[, at])` | `api.developers().user(id[, AccessToken.of(id, at)])` | 已迁移 |
| `tools.accountInfoDevelopers(appId, id)` | `AccountAssembler.of(api).info(id)` | 已迁移 |
| `clan.developers(appId).userSearchClanDevelopers(id)` | `api.developers().accountClan(id)` | 已迁移 |
| `clan.developers(appId).clanInfoDevelopers(clanId)` | `api.developers().clanInfo(clanId)` | 已迁移 |
| `clan.developers(appId).searchClanDevelopers(tag)` / `.season()` | `api.developers().clanSearch(tag)` / `.clanSeason([language])` | ✅ 已迁移 |
| `ship.developers(appId).shipList()/shipOperList()/shipBadges()` | `api.developers().ships(id[, at])` / `.shipsOper(id[, at])` / `.shipBadges(id)`（RU 徽章显式拒绝） | ✅ 已迁移 |
| `ship.vortex().shipList(type[, token])` / `shipListMap(...)` | `api.vortex().ships(accountId, type[, ShareToken])`（type 不支持当前服抛 `UnsupportedOnServerException`；多类型自行为循环调用） | ✅ 已迁移 |
| `clan.vortex().clanInfoVortex/clanUserListInfoVortex/searchClanVortex/userSearchClanVortex` | `api.clans().clanInfo(id)` / `.members(id[, type, season])` / `.search(tag)` / `.accountClan(id)` | ✅ 已迁移 |
| `WowsLootBox/WowsBox/WowsResources/RequestVortexResourcesInfo.request(...)` | `api.resources().lootbox(id[, lang])` / `.lootboxes(lang)` / `.items(lang)` / `.glossary(lang)`（POST 走管线；PT 用 `api.pt()`） | ✅ 已迁移 |
| `new ClanRankUtils().getRanks(server, season)` | `api.clans().ladder(season)`（整季游标分页；单页 `ladderPage(season, cursor)`。`season<=0` = 最新赛季——旧实现该路径发空值被服务端 422 静默吞成空表，新实现修正；失败不再吞） | ✅ 已迁移 |
| `HttpCodec.updateTimeout(n)` | `WowsApi.of(server).timeout(n)`（进程级共享，设一次即可） | 已迁移 |
| `HttpCodec.updateProxySelector(sel)` | `api.proxy(sel)`（进程级共享；null = 直连） | 已迁移 |
| `HttpCodec.client()` 自建并传参 | 3.0 无需——管线内部使用 `HttpClientProvider` 共享 client | 已迁移 |
| `new WowsEncyclopediaTools(client, server).developers(appId).glossary()` | `api.developers().glossary()` | ✅ 已迁移 |
